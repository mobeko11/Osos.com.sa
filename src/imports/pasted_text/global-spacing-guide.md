Adjust the **global spacing system across the entire website**. Do not redesign the website or change its content, colors, typography, components, or overall layout. The goal is only to create a more consistent, balanced, and visually comfortable spacing system.

## Global Spacing System

Use an **8-point spacing system** as the foundation for the entire website.

Use only consistent spacing values based primarily on:

* 8px
* 16px
* 24px
* 32px
* 40px
* 48px
* 64px
* 80px
* 96px
* 128px

For very small internal spacing, 4px can be used only when necessary.

Do not use random values such as 13px, 19px, 27px, 35px, or inconsistent arbitrary spacing.

Create reusable global spacing tokens and apply them consistently across all pages and components.

## Spacing Hierarchy

Use spacing based on the relationship between elements.

### 8px

Use for very closely related elements:

* Icon and text
* Label and related information
* Small inline elements
* Small internal gaps

### 16px

Use for closely related content:

* Title and short description
* Form label and input
* Elements inside compact components
* Small card content gaps

### 24px

Use for normal component spacing:

* Card internal content
* Gap between related groups
* Form fields
* Text blocks and related actions

### 32px

Use for larger component separation:

* Padding inside larger cards
* Gap between cards
* Separation between major groups within a section

### 40px / 48px

Use for clear separation between content groups:

* Heading group and main content
* Large cards
* Important component groups

### 64px / 80px

Use for section-level spacing:

* Internal vertical spacing inside standard sections
* Separation between major blocks

### 96px / 128px

Use only for large page-level spacing:

* Large desktop sections
* Hero sections
* Major visual separation

Do not automatically use large spacing everywhere.

## Important Visual Rule

The website should feel:

**Balanced, breathable, and organized — but not empty.**

Avoid excessive whitespace.

Do not create large empty areas between sections unless there is a clear visual reason.

At the same time, do not make sections or components feel crowded or stuck together.

Use **visual hierarchy and content relationships** to determine the spacing.

Elements that belong together should have smaller spacing.

Elements that belong to different groups or sections should have larger spacing.

Example hierarchy:

* Label → Heading: 8–16px
* Heading → Description: 16–24px
* Description → CTA: 24–32px
* Content groups: 32–48px
* Section heading → Section content: 40–64px
* Between major sections: 64–96px depending on the content

## Sections

Review the vertical spacing between all sections.

Use a consistent rhythm.

Suggested direction:

### Desktop

* Standard section top/bottom padding: 80–96px
* Compact sections: 64px
* Large or Hero sections: 96–128px

### Tablet

Reduce spacing gradually based on available screen size.

Do not simply keep desktop spacing values.

### Mobile

Use tighter but still comfortable spacing:

* Standard sections: 48–64px vertical padding
* Compact sections: 32–48px
* Hero sections: 64–96px depending on content

Avoid excessive vertical scrolling caused by unnecessarily large whitespace.

## Containers

Standardize the spacing inside all page containers.

Use consistent horizontal padding:

### Desktop

32–64px depending on viewport size.

### Tablet

24–32px.

### Mobile

16–24px.

Ensure all sections align consistently to the same container system where appropriate.

## Cards

Standardize card spacing across the entire website.

Suggested values:

* Compact card padding: 16px
* Standard card padding: 24px
* Large feature card padding: 32px

Internal spacing:

* Icon → Title: 16px
* Title → Description: 8–16px
* Description → CTA: 24px

Card-to-card gap:

* 16px for compact grids
* 24px for standard grids
* 32px for larger layouts

Do not use excessively large padding inside cards, especially when the content is short.

## Typography Spacing

Create consistent spacing around text:

* Eyebrow / Label → Heading: 8–16px
* Heading → Subheading: 16–24px
* Paragraph → Paragraph: 16px
* Description → CTA: 24–32px

Make sure Arabic typography has comfortable line-height and does not feel crowded vertically.

## Forms

Standardize all form spacing:

* Label → Input: 8px
* Input → Next field: 16–24px
* Form groups: 24–32px
* Form → Submit button: 24–32px

Inputs and buttons should have consistent internal padding and height based on the same spacing system.

## Navbar and Header

Review the header spacing as well:

* Logo and navigation should have balanced spacing.
* Navigation links should not feel too close or too far apart.
* Use consistent gaps based on the spacing scale.
* Maintain comfortable horizontal padding on all screen sizes.

## Final Goal

Review the entire website and normalize all:

* Section spacing
* Margins
* Padding
* Grid gaps
* Card spacing
* Typography spacing
* Button spacing
* Form spacing
* Header spacing
* Modal spacing

Use the 8-point system consistently, but do not apply spacing mechanically.

The final result should feel:

**Modern · Clean · Premium · Balanced · Comfortable for the eye**

The website should have enough whitespace to feel premium and easy to read, without feeling too empty or forcing the user to scroll through unnecessarily large gaps.

Prioritize **visual balance and content hierarchy** over using the largest spacing values everywhere.
