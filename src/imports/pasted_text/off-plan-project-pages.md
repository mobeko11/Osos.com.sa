# 21. UX / Visual Direction

التصميم يجب أن يشعر المستخدم بأنه يتعامل مع منصة عقارية احترافية.

استخدم:

* Typography عربية Premium
* Borders خفيفة
* Shadows ناعمة
* Cards نظيفة
* Generous spacing
* Clear hierarchy
* Minimal icons
* Subtle hover animations

لا تستخدم:

* Gradients مبالغ فيها
* كثرة الألوان
* Shadows قوية
* Cards مزدحمة
* Animations مبالغ فيها

---

# 22. Mobile UX

على Mobile:

* الفلاتر داخل Accordion.
* جدول الوحدات يتحول إلى Cards أو List View responsive بدلاً من جدول ضيق.
* Unit Details تتحول إلى Full-screen Modal / Bottom Sheet.
* CTA يبقى واضحاً وسهل الضغط.
* Buttons تكون Touch-friendly.
* لا تجعل المستخدم يضطر إلى Zoom لرؤية بيانات الوحدة.

# 23. Important Real Estate / Compliance Detail

لأن هذه الصفحة خاصة بمنتج **البيع على الخارطة** في السعودية، أضف مكاناً واضحاً لبيانات الترخيص/المعلومات النظامية الخاصة بالمشروع عندما تكون متوفرة، بدلاً من إخفائها داخل التفاصيل.

ولا تعرض أي معلومات مثل رقم ترخيص أو حساب ضمان أو حالة قانونية إلا إذا كانت البيانات مؤكدة ومقدمة من الشركة.

كما يجب ألا يوحي زر **"اهتمام"** بأنه إتمام حجز أو شراء للوحدة؛ هو فقط **طلب اهتمام / استفسار** ما لم يكن هناك نظام حجز فعلي معتمد.

هذا مهم خصوصاً أن تنظيمات البيع على الخارطة في السعودية تتطلب الإفصاح عن حالة المشروع وخططه المستقبلية، وتنظم موضوع مبالغ الحجز وحساب الضمان في الحالات التي يتم فيها تحصيل مبالغ حجز.

* صفحة **مشاريعنا**
* Section **مشاريعنا** في Homepage
* Project Cards الموجودة في Homepage
* نظام التواصل
* Request Interest Modal
* بيانات الوحدات
* صفحة تواصل معنا

إذا ضغط المستخدم على مشروع من Homepage:

→ ينتقل إلى Project Details.

إذا ضغط على وحدة:

→ يفتح Unit Details.

إذا ضغط **اهتمام**:

→ يفتح Request Interest Modal مع البيانات المحددة مسبقاً.
